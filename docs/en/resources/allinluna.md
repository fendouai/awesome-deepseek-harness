## One-liner

Resource-aware multi-agent orchestration for Codex and DeepSeek Harness (All in Flash DSH plugin).

## About

[简体中文](README.zh-CN.md) <p align="center"> </p> Give All in Luna one big goal. It turns the work into independent top-level tasks: **run what can run in parallel, wait only on real dependencies, keep each task's context separate, and bring the results back together.** Each task can still use its own subagents, tools, Skills, or MCPs. **Parallel across tasks. Recursive inside tasks.** <p align="center"> </p> ---
