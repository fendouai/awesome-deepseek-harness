## About

DeepSeek Harness is built on an architecture where every capability — tools, UI, memory, orchestration — is a [Cordis](https://github.com/cordiverse/cordis) plugin. This list tracks the best community plugins and ecosystem projects. **Find more:** add the [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic to your repo for discoverability. **Website:** browse the searchable catalog at **[awesome-deepseek-harness-plugins.pages.dev](https://awesome-deepseek-harness-plugins.pages.dev/)** (source in [`website/`](website/), built with Astro + Bun, hosted on Cloudflare Pages — redeploy with `cd website && bun run deploy`).
