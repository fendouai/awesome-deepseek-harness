## About

An independent, evidence-led directory for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) plugins. Every listed entry was inspected at an immutable commit for its bundle manifest, referenced patch, license signals, package identity, lifecycle scripts, and material capability signals. This is a compact reviewed subset, not a mirror of every repository carrying the `dsh-plugin` topic. It complements the broad [Awesome DeepSeek Harness Plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) discovery list with fixed-source evidence and an explicit hold queue.
