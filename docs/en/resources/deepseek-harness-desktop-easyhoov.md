# deepseek-harness-desktop

> ⭐ 4 · ✅ active · client

## One-liner

Windows desktop app for DeepSeek Harness: installer, themes, in-app plugin marketplace, model routing, and updates.

## About

Harness Desktop 是面向 Windows 的开源桌面客户端，直接运行并显示官方 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web UI。 本项目由社区维护，不是 DeepSeek 官方应用，也不代表 DeepSeek 官方背书。
