## 📦 Install

```bash
# 1. 安装依赖
pnpm install

# 2. 启动开发服务器（热更新）
pnpm run docs:dev

# 3. 构建生产版本（输出到 docs/.vitepress/dist）
pnpm run docs:build

# 4. 本地预览构建产物
pnpm run docs:preview
```
