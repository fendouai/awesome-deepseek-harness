# dsh-agent-teams

> ⭐ 312 · ✅ active · agent

## One-liner

Multi-agent team-oriented extensions for DSH.

## About

`dsh-agent-teams` turns the current DeepSeek Harness session into a captain that can assemble durable sub-agents, split a goal into dependency-aware tasks, and coordinate work through direct messages. Ask in natural language. The plugin provides the team protocol, nine coordination tools, persistent state, and a live Web UI—without requiring a separate workflow engine. <p align="center"> </p>
