# dsh-auto-continue

> ⭐ 15 · ✅ active · workflow

## One-liner

Auto-resumes interrupted DSH Web requests: failure classification, adaptive retry, configurable continue message and browser notifications.

## About

For [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh web`): whenever a request in the web GUI gets interrupted by a **non-human cause**, the plugin simulates the user typing **「继续」** and sends it, so the agent keeps working without manual intervention.
