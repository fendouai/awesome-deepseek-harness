## About

一本科普向的源码级架构拆解书：把 DeepSeek Harness（dsh）这台"一切皆插件"的机器，用咖啡馆聊天的方式讲清楚。目标读者是对 AI 编程工具有好奇心的开发者、产品经理、技术爱好者——不要求写过 agent 代码，不要求懂 TypeScript。
