## 📚 Learn more

**🗺️ 推荐使用方式**

提出问题 → 连接项目 → 并行推进 → 沉淀结论 │ │ │ │ 写下目标 导入文献/ Chat Graph 结论存为 与材料 代码目录 分支试错 科研记忆 1. **从问题开始**：写下研究目标、已有材料和期望产出 2. **连接项目**：导入项目目录，让它直接参考你的文件与笔记 3. **分支推进**：在 Chat Graph 中同时探索多条假设路线 4. **沉淀复用**：可靠结论存入科研记忆，实验过程自动进账本
