## 📦 Install

```bash
# 1. 完全退出 DSH（包括托盘进程）
# 2. 克隆仓库并添加插件
git clone https://github.com/yunxiiQwQ/dsh-maid-whale-webUI.git
cd dsh-maid-whale-webUI
dsh plugin --profile web add ./maid-whale-webui

# 3. 启动 DSH Web UI
dsh --profile web
```

## 🚀 Quick Start

```bash
# 更新：在仓库目录拉取最新版本，然后重启 DSH
git pull
```
