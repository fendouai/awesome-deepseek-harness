## About

**面向 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的 Windows 桌面启动器与插件管理器** 一个下载即用的启动器：管理 DSH 本体、插件、API Key 与运行配置，无需预装 Node.js。 **简体中文** · [English](README.en.md) ---

## 📦 Install

```bash
# 直接运行，不需要先安装
npx dsh-melody-launcher

# 或全局安装后运行
npm install -g dsh-melody-launcher
dsh-melody-launcher
```
