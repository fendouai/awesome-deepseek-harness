# dsh-mneme

> ⭐ 10 · ✅ active · plugin

## One-liner

Local cross-session memory with memory sovereignty: SQLite + human-editable Markdown mirror and background autoDream consolidation.

## About

`dsh-mneme` 是一个 [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness) 插件，为 Agent 提供持久的跨会话记忆能力。**Mneme**（Μνήμη）——希腊记忆女神 Mnemosyne 之名，掌管记忆与梦境，正如 autoDream 在后台巩固记忆。 不同于把记忆锁进数据库的插件，Mneme 把记忆**写成你读得懂的 Markdown**——你始终握着记忆的主权：看得见、改得动、删得掉，记忆这回事不该让 Agent 一个人说了算。
