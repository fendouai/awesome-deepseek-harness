## About

A DeepSeek Harness plugin that gives the composer shell-style **prompt history recall**.  Current version: **0.6.1**.  - Press **↑** in an empty composer to load the last prompt you sent; - press **↑** again to walk further back; - press **↓** to walk forward and finally return to the empty draft;
