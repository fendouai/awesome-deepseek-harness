# dsh-personal-directive

> ⭐ 0 · 🧪 experimental · plugin

## One-liner

Personal directives with system-prompt injection, tools and a top-bar runtime toggle (framework version with replaceable neutral placeholders).

## About

DeepSeek Harness 的「无限一代」二次开发**框架版**：保留原版仓库的插件形态（系统提示词注入 + 工具 + 顶部运行时开关），但**不随包发布原版提示词内容**——改用中性占位指令，用户可自行替换为自己的个人指令。
