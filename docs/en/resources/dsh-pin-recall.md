## About

Pin assistant replies (or tool/text evidence) in a DeepSeek Harness session, then recall them into the model turn — with a Web card button. [中文文档](./README.zh-CN.md)

## 📦 Install

```bash
# from a built checkout
dsh plugin --profile web add /absolute/path/to/dsh-pin-recall

# or from GitHub (after you publish)
dsh plugin --profile web add github:YOUR_USER/dsh-pin-recall
```

## 🚀 Quick Start

```bash
npm install
npm run build
```
