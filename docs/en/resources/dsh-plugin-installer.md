# dsh-plugin-installer

> ⭐ 6 · ✅ active · plugin

## One-liner

Marketplace plugin that integrates DeepSeek Harness with the GitHub plugin ecosystem.

## About

An in-app marketplace and Profile switcher for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). DSH Plugin Installer adds a **Plugin marketplace** tab to the official Web UI under **Settings → Plugins**. It discovers repositories from the GitHub `dsh-plugin` and `dsh` topics, verifies that a repository is a real DSH bundle, installs it at a pinned commit, and helps users open another Web Profile without leaving the UI.
