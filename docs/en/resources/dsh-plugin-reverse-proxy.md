## One-liner

> DSH Web 局域网/公网访问插件：内置反向代理 + 免 Token 登录，手机同 Wi-Fi 直连；公网访问需开关 + 访问密钥（地址变成 /密钥，密钥可一键随机生成）；可选 IPv6 监听、额外端口转发（把只监听本机的插件端口一起放出去）、访问 IP 黑名单与一键重置。

## About

DSH Web 局域网/公网访问插件：内置反向代理 + 免 Token 登录，手机同 Wi-Fi 直连；公网访问需开关 + 访问密钥（地址变成 /密钥，密钥可一键随机生成）；可选 IPv6 监听、额外端口转发（把只监听本机的插件端口一起放出去）、访问 IP 黑名单与一键重置。
