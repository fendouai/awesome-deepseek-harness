## 🚀 Quick Start

```bash
npm run list
node bin/dsh-plugins.mjs search vision
node bin/dsh-plugins.mjs info Anionex/dsh-vision-toolkit
```

## 📚 Learn more

**安装插件**

安装命令默认只预览，不执行上游代码： node bin/dsh-plugins.mjs install Anionex/dsh-vision-toolkit --profile web 确认上游代码和许可证后，加入 `--execute` 执行安装。
