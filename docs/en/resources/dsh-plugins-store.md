# dsh-plugins-store

> ⭐ 38 · ✅ active · plugin

## One-liner

Static directory site that automatically collects and categorizes GitHub dsh-plugin topic projects.

## About

- 自动收录公开的 `dsh-plugin` Topic 仓库 - 根据 GitHub Topics 识别项目类型和功能分类 - 支持名称、作者、描述和标签搜索 - 支持分类、项目类型和更新时间等筛选排序 - 提供项目详情、分类依据和同标签项目页面 - 显示“发现 → 识别 → 结构检查 → 实机验证”进度，并支持按当前验证状态筛选 - 每 30 分钟自动同步 GitHub 仓库数据 - 提供可安装的 DSH Web 插件，通过 `/store`、会话工具栏和设置页浏览同一目录，并在风险确认后支持一键安装
