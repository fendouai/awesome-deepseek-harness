## About

One-click prompt booster 💪 — if the result is too short, continue generating 🔜; if you don't like it, regenerate 🔄. Your history is auto-saved 🕐 and you can roll back ↩️ anytime. Results sync back to the input box with a line-by-line diff view. 🗺️ A visual UI 🎨 lets you place the prompt 🪄 button and its icon 📍 wherever you want.
