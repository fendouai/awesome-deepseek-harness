## About

DSH 按需代理插件：需要时才拉起 mihomo 内核，用完空闲自动关闭 —— 平时不占端口、不留后台进程。首次运行自动下载内核（约 61MB），内置设置界面可填订阅或一键导入本机 FlClash 配置。内核与 Windows 系统代理是两枚独立开关：内核只绑 127.0.0.1，起停不改变你的网络环境；动系统代理前先备份原值，关的时候逐字段精确还原（连绕过列表都一字不动），别人占着时只报告不抢。自带节点面板：列分组、列节点、切换后回读确认、一键测延迟。检测到全屏游戏只是不启用代理；检测到 FlClash 等其它代理已在运行就静默让路。On-demand proxy for DeepSeek Harness.
