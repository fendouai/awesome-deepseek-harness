# dsh-quickstart

> ⭐ 0 · ✅ active · client

## One-liner

Desktop launcher for DeepSeek Harness - start dsh web with no console window and auto-open the browser. Tested on Windows; macOS/Linux in progress.

## About

<p align="center"> </p> Launch [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) from a desktop icon — `dsh web` starts **without a console window**, then the browser **opens automatically** once the web UI is ready. No more typing `npx @deepseek-ai/dsh web` and waiting for the page by hand — this double-click-and-go wrapper handles startup, readiness polling, and browser opening.
