# dsh-plugin-spur

> ⭐ 3 · ✅ active · workflow

## One-liner

Hang a whip in the chat stream: flick it (>2.0 px/ms) to send the agent a 'go work' message.

## About

一根悬挂在 DSH 聊天流中的辫子（皮鞭）。抓住辫梢甩动——速度足够快时，向 agent 发送一条 `go work!` 消息，鞭策它去干活。
