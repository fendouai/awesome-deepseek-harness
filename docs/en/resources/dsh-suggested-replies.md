# dsh-suggested-replies

> ⭐ 3 · ✅ active · plugin

## One-liner

Predicted next-message candidates above the DSH Web composer, one click to fill the draft.

## About

DSH Web 的“预测回复”插件：AI 回复结束后，生成几条用户下一步可能会发送的消息候选，并将它们显示在**聊天输入框上方**。点击候选只会将文本填入输入框，**不会自动发送**。
