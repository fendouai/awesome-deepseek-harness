## 📦 Install

```bash
# 用户环境变量（或当前会话 $env:...）
# DSH_TELEGRAM_TOKEN = BotFather token
# DSH_TELEGRAM_ALLOWED_USER_IDS = 数字ID

dsh plugin --profile web add github:hi-wenw/dsh-telegram-channel
dsh web
```

## 🚀 Quick Start

```bash
dsh plugin --profile web add D:\path\to\dsh-telegram-channel
```
