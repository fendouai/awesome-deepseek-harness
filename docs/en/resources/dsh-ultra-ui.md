## ✨ Key Features

- 📦 折叠任意 Tool Call，包括第三方插件新增的工具。
- 👀 折叠状态仍显示工具名和有用的参数摘要。
- 🔍 展开查看准确参数、结果、错误和轨迹检查操作。
- 🔄 只从已记录的 call/result block 派生状态，实时展示与会话回放一致。
- 🧠 不增加模型工具、系统提示或请求 token。

## 📦 Install

```bash
dsh plugin --profile web add github:havingautism/dsh-ultra-ui
dsh web
```
