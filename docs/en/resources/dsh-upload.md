# dsh-upload

> ⭐ 0 · ✅ active · plugin

## One-liner

Upload button for the DSH web composer: local files land as bytes in the session workspace (.uploads/<sessionId>/), the absolute path is appended to the draft (visible and editable), and the agent reads the file with its own fs tools. Zero dependencies. / DSH Web 的上传按钮:本地文件字节落盘到会话工作区 .uploads/<会话ID>/,绝对路径追加进输入框(可见可编辑),AI 用 fs 工具直接读取。零依赖。
