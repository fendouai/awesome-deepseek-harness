## About

**给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的纯文本 DeepSeek 一双眼睛——默认走豆包 Web，零成本、免 API key。** [English](README.en.md) | [简体中文](README.md) =20" />

## 📦 Install

```bash
dsh plugin --profile web add dsh-vision-web
```

## 🚀 Quick Start

```bash
# 在 Windows 侧：连接一个开了调试端口的 Chrome，然后运行
   node bridge.mjs    # 详见下方「豆包桥接」章节
```

## 📚 Learn more

**使用**

1. **面板**：会话头部点「识图」→ 添加/粘贴图片 → 提示词 → 模式/档位/通道 → 识别。 2. **对话流**：模型选择器选 `deepseek-vision` 路由，粘贴图片发送——模型自动调用识图。
