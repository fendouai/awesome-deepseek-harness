# dsh-web-review

> ⭐ 15 · ✅ active · plugin

## One-liner

DeepSeek Harness Web GUI 的网页预览与元素批注插件，让 AI 根据可视化反馈直接修改前端源码。

## About

[English](./README_en.md) 在内置浏览器中，像使用设计工具一样选择页面元素、填写修改意见，并临时调整文本、颜色、字体、尺寸、间距、边框与效果。确认发送后，Agent 会结合页面批注修改当前工作区中的源码。 <p align="center"> </p> <p align="center"> </p>
