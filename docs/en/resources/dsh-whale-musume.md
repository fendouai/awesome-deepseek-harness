# dsh-whale-musume

> ⭐ 48 · ✅ active · plugin

## One-liner

Whale-girl desktop pet for the DSH web UI: pat-to-raise growth, work-state poses, 494 dialogue lines, 30 achievements, drag physics, theme sync and a built-in settings panel; local-first, zero telemetry (MIT, 102 unit tests). / 元气鲸鱼娘桌宠：摸头养成、工作状态联动、494 条台词与 30 项成就；全本地零遥测。

## About

- 默认悬浮形态（200px），支持鼠标拖拽； - 拖拽时切换「被拎起来」立绘，身体随光标移动方向自然摇摆； - **拖拽惯性**：松手后按瞬时速度滑行一小段并旋转回正，撞到屏幕边缘就「抓住」边缘停住；轻放只做一次轻微回弹，位置在滑行结束后才保存； - 待机时保持稳定表情，随机出现喝咖啡、伸懒腰、吃东西等日常小动作； - 待机与工作状态之间使用「下压 → 换图 → 弹起」的动势遮断过渡，不会叠影，不会闪黑； - 在设置里关掉她之后，左下角会留一枚唤回按钮（🐋），点一下就把她叫回来，不会再「消失得找不着」。
