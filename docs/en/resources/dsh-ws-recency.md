## About

DSH 侧栏的七件事：工作区分组按最近活跃排序、过期历史自动折叠、运行中/未读/需跟进三色标记、所有置顶会话汇总到顶部一个区、删除会话到可恢复的回收站（归档会话也在同一个面板里管理）、按来源拆分、并将参数与结果分段的 token 消耗统计、把会话移动到另一个工作区，外加跨会话的内容搜索（点结果直接跳到说过那句话的那一轮）。单独装上就有效，不依赖其它插件。
