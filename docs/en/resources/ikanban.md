# ikanban

> ⭐ 10 · ✅ active · integration

## One-liner

Monorepo for the iKanban browser-surface fork for DeepSeek Harness.

## About

[English](./README.en.md) | 简体中文 iKanban 是一个面向键盘操作、基于 [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness) 的多智能体编码工作空间。它专为跨项目地驱动、审查和协调并行智能体工作而构建，将会话管理、差异审查和项目感知导航集于一处。 本 monorepo 包含公开发布的 DSH bundle，以及完整浏览器界面的私有可编辑 fork。
