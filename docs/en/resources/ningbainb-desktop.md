## 📚 Learn more

**下载与安装**

1. 打开 [GitHub Releases](https://github.com/ningbainb/deepseek-harness-desktop/releases/latest)。 2. 下载 `DeepSeek-Harness-Desktop-Setup-<版本号>-x64.exe`。 3. 运行安装程序完成安装。 4. 启动 **DeepSeek Harness Desktop**。 安装包已经包含 DSH、桌面插件、皮肤、pnpm、MinGit 与所需原生依赖，不需要额外安装 Node.js 或 Git。 如果 GitHub 下载速度较慢，也可以加入页面顶部的用户交流群获取同步提供的安装包。
