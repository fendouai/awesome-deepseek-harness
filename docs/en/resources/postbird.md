## About

A native Cordis plugin for DeepSeek Harness that reads mail over IMAP, cites source messages in replies, requires confirmation before sending, and generates Word, Excel and PPT files locally. 面向 DeepSeek Harness 的原生 Cordis 插件，通过 IMAP 只读收件，回复附原文出处，发信前需二次确认，并在本机生成 Word、Excel、PPT 文件。
