## About

TurtlePlugin-DSH_ComputerUSE grants DeepSeek Harness computer control, similar to Codex/Qwen Code. It uses sandboxing and explicit authorization, with an app whitelist and first-use Allow prompt. Two modes: Foreground Takeover and Background; Background uses a separate virtual cursor, so your physical mouse/keyboard remain unaffected.
