> ⭐ 2 · ✅ active · integration

## One-liner

Unofficial: drive your own dsh as a native VS Code chat agent.

## About

[中文文档](readme.zh.md) · [English](README.md) An unofficial VS Code extension that registers [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) as a **chat session target** in VS Code's native agent sessions view — the same surface that hosts Claude Code and Codex — rather than shipping another webview chat panel. Status: **M0–M5 implemented.** A VSIX builds, installs and activates with its proposed APIs granted. - [docs/plans/0001-vscode-chat-session-provider.md](docs/plans/0001-
