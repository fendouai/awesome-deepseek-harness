## 一句话介绍

轻量快速终端插件，直连 DSH 运行时。

## 详细介绍

[English](README.en.md) | 中文 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai/deepseek-harness) 的轻量、快捷终端 UI 插件。它直接衔接 DSH 的 Agent、工具、权限和 Session 服务，不重复实现 Harness 运行时。 项目简称 **DSH-TUI**，中文昵称为 **“单身汉 TUI”**，取自 DSH 的谐音。
