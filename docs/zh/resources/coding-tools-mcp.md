# Coding Tools MCP

> ⭐ 787 · ✅ 活跃 · 集成

## 一句话介绍

面向编码的 MCP 工具集：让任何 AI Agent 获得编码能力。

## 详细介绍

Coding Tools MCP is a **model-neutral coding runtime** served over the [Model Context Protocol](https://modelcontextprotocol.io): file reading and search, structured multi-file patches, command execution, interactive sessions, and git — one server that any MCP client can drive. Claude Desktop, Claude Code, Cursor, Cline, or an agent you build yourself all get the same 18 battle-tested tools, confined to one workspace, gated by permission modes.
