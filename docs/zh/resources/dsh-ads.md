## 详细介绍

简体中文 | English 把 DeepSeek Harness 变成 2005 年门户网站。连 inference 都逃不过广告。 广告是假的，插件是真的，抽到 V4 Pro 的希望也是真的渺茫。 `dsh-ads` 会在侧栏、对话、推理中途和右下角塞入一整套虚构广告。它看起来会暂停 inference，实际上模型一直在后台工作，只是后续回答和工具调用要等广告结束才显示。 插件不会只拿自己开涮。GitHub 上带 [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic、且最近两周更新过的公开插件会进入推荐位，点击广告就能打开真实仓库。仓库换到个人账号或其他组织后仍能被发现。

## 📦 安装

```bash
dsh plugin --profile web add github:Nagi-ovo/dsh-ads
# 如果 dsh web 正在运行，重启后刷新页面
```
