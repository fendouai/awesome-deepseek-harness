## 详细介绍

DeepSeek Harness Web 的 evidence-backed 内置 capability Inspector；9 个经过审阅的 UI controls 只是极窄、fail-closed 的附加能力。 本插件位于 **设置 → 插件 → 内置开关**。它显示由 Host 生成的 capability inspection：审阅事实、profile override、可持久化性、兼容性和 mutation eligibility 均由服务端计算。旧 catalog screenshot 不再代表当前 Inspector，已移除而不以示意图替代。
