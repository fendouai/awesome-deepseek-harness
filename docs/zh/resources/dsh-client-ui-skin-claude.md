## ✨ 核心特性

- 暖黑（#141413）画布 + Anthropic 陶橙（#d97757）点缀
- 字体模式：
- 细滚动条、陶橙选中 / 焦点、胶囊徽章
- 亮 / 暗双主题，跟随系统切换

## 📦 安装

```bash
dsh plugin --profile web add @pakiknowledge/dsh-client-ui-skin-claude
```

## 🚀 快速开始

```bash
dsh plugin --profile web add github:PAKIKNOWLEDGE/dsh-client-ui-skin-claude
```

## 📚 更多信息

**特性**

- **Anthropic 原生（默认）**：UI 用 Anthropic Sans，对话正文用 Anthropic Serif，代码用 Anthropic Mono - **皮肤衬线**：保留原来的衬线 UI 风格 - **系统默认**：不覆盖 DSH 字体

**安装**

从 npm 安装（推荐，预构建免授权）： dsh plugin --profile web add @pakiknowledge/dsh-client-ui-skin-claude 或从 GitHub 安装： dsh plugin --profile web add github:PAKIKNOWLEDGE/dsh-client-ui-skin-claude 装完重启 `dsh web`，刷新页面。
