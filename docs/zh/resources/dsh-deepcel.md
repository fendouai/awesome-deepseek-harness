# dsh-deepcel

> ⭐ 8 · ✅ 活跃 · 插件

## 一句话介绍

Excel 风格电子表格皮肤。

## 详细介绍

本仓库仍处于内部测试阶段，仓库为私有可见性。获得仓库访问权限后： git clone https://github.com/dsh-external/dsh-deepcel cd <harness> dsh plugin --profile web add ../dsh-deepcel/deepcel Deepcel 加载即生效，卸载即复原；其 wiring id 为 `ui-skin-deepcel`。
