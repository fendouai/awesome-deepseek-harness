# DeepSeek-Harness-billing-plugin

## 一句话介绍

账户余额 + 按模型剩余任务估算，带会话费用台账。

一个 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 插件，在 Web 会话头部直接显示你的 **DeepSeek 账户余额**，以及**大概还能跑多少个任务**。
