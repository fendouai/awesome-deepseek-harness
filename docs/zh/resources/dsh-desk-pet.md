> Always-on-top DeepSeek Harness desktop pet. Default whale, four skins, four silent states.

## 详细介绍

English · 简体中文 一只跟着你的 agent 换表情的 macOS 桌宠。 换成你自己的猫也行。 进去一张照片，出来六个状态：空闲、干活、等你、报错、开心、睡着。 生图跑的是你自己的工具、烧的是你自己的额度，我这边不往任何地方传东西。 它是一个真的 macOS 窗口，不是塞进 DSH 页面里的挂件。 盖在我正在用的一切上面，全屏也盖得住，不用我告诉它现在该显示什么。 ---

## 📦 安装

```bash
dsh plugin --profile web add deepseek-desk-pet
dsh web
```

## 🚀 快速开始

```bash
dsh plugin --profile web add deepseek-desk-pet@latest
```

## 📚 更多信息

**安装**

已经有 DSH 的话，一条命令： dsh plugin --profile web add deepseek-desk-pet dsh web 装完宠物就浮在桌面上了，DSH 页面本身不会被塞任何东西。 从旧版本升级得带 `@latest`： dsh plugin --profile web add deepseek-desk-pet@latest 不带的话写进去的是 `^0.x` 范围，而 caret 作用在 `0.x` 上会锁住次版本号，`^0.1.0` 永远不接受 `0.2.0`。裸命令会报一句 Already up to date，旧版本原地不动。 不想装 DSH、只想看宠物：克隆下来跑 `./bin/dsh-desk-pet`。 想跟 main 分支而不是发布版： dsh plugin --profile web add github:anneheartrecord/dsh-de
