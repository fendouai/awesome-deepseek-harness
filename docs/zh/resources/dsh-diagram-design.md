## 详细介绍

diagram-design（v2.6，作者 Cathryn Lavery，MIT）的DSH插件版本——一个"教 agent 画图"的技能：把图表画成单文件 HTML + 内联 SVG，用一套 editorial 设计系统（1 个强调色、1px 细线、无阴影、4px 网格、密度 4/10）。45 种图表类型，还支持 draw.io / Mermaid / Excalidraw 导入和 SVG / PNG 导出。
