## 📦 安装

```bash
cd ~/.dsh/profiles/web && pnpm install && dsh web
```

## 🚀 快速开始

```bash
agent-default-model:
  model: deepseek-v4-flash    # 或 deepseek-v4-pro
  reasoningEffort: high       # off（关闭思考/最快）/ high（默认）/ max（最强）
```
