## 详细介绍

**Cited memory over DSH's lossless session log.** Distilled facts that can always escalate back to the exact original context. `dsh-memory` is a DeepSeek Harness bundle. When a session ends, a background distillation pass extracts durable facts — user preferences, project decisions, environment quirks, corrections — into small markdown files under `~/.dsh/memory/`.
