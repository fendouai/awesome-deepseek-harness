## ✨ 核心特性

- 余额小部件
- 控制台 启动/重启/关闭
- 新增液态玻璃风格外观，可自定义背景图片
- 系统托盘常驻 + 托盘三态状态灯、全屏沉浸 + 悬浮球、开屏动画、关闭至托盘
- 悬浮球，开屏动画

## 📦 安装

```bash
pnpm install        # 首次需要下载 Electron,网络慢时可在 .npmrc 配置 electron_mirror
pnpm dev            # 开发模式(HMR)
pnpm build          # 构建 main / preload / renderer 到 out/
pnpm dist           # electron-vite build + electron-builder --win → release/
```
