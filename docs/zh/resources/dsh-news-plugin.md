# dsh-news-plugin

> ⭐ 1 · ✅ 活跃 · 插件

## 一句话介绍

RSS/新闻摄入插件：返回结构化的标题/链接/来源/日期/摘要，供模型排序与简报。

## 详细介绍

DeepSeek Harness 新闻采集工具插件。注册一个 `news_fetch` 工具：抓取 RSS 新闻源并解析为结构化条目，供模型做五维评分筛选与简报编排。 **设计原则：采集与解析是确定性工作交给插件，评分/筛选/写作交给模型。** 不依赖第三方包（Node 原生 fetch + 正则解析）。
