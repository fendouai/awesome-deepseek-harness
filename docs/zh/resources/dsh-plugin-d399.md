# dsh-plugin-d399

> ⭐ 5 · ✅ 活跃 · 插件

## 一句话介绍

模型生成时右下角弹出小游戏菜单：Wordle/消消乐/192 款参数化小游戏。

## 详细介绍

当模型正在生成响应时，右下角弹出一个蓝鲸游戏弹窗。点击「来♂」展开游戏菜单，内置 Wordle + 消消乐 + **192 款参数化小游戏**（覆盖反应/解谜/策略/街机/问答/卡牌等品类，同族变体折叠成组），并支持自定义网页书签。等待不再寂寞。
