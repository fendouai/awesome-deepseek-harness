## 详细介绍

1. **Fork 或新建仓库**：仓库名必须为 `你的用户名.github.io`（例如 `dsh-plugin.github.io`）。 2. **推送文件**：将本压缩包内**根目录的所有文件**推送到仓库 `main` 分支。 3. **启用 Pages**：仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支选 `main` / `/ (root)`。 4. **等待构建**：1-2 分钟后访问 `https://你的用户名.github.io/` 即可。

## 🚀 快速开始

```bash
# 方式一：Python 内置服务器
cd dsh-plugin-release
python3 -m http.server 3000
# 访问 http://localhost:3000/

# 方式二：bun
bun install
bun run dev
```
