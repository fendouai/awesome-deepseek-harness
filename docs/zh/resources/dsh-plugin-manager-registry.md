## 详细介绍

The discovery engine of `dsh pm` — find dsh plugins by merging three independent sources into one deduped, sorted, **offline-tolerant** registry: 1. **awesome-list** — the [awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) README, parsed under its category headings (config `awesomeUrl`). 2. **GitHub topic** — repo search for the `dsh-plugin` topic via the `gh` CLI, with a plain `api.github.com` https fallback. 3. **npm keyword** — `npm search --json <keyword>` (config
