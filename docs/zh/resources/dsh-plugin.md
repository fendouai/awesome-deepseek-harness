## 详细介绍

这是一个 Tabbit 浏览器为 Deepseek Harness 提供的一个 plugins。你可以在 Deepseek Harness 中安装这个插件，给 Deepseek Harness 提供控制 Tabbit 浏览器的能力。

## 📦 安装

```bash
brew install node
npm install -g @deepseek-ai/dsh
```

## 🚀 快速开始

```bash
winget install OpenJS.NodeJS.LTS
```
