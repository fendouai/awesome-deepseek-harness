# dsh-prompt-studio

> ⭐ 2 · ✅ 活跃 · 插件

## 一句话介绍

带实时预览编辑用户与内置系统提示词片段。

## 详细介绍

Prompt Studio 的 DeepSeek Harness 插件分发形态。插件在对话页注册 **Prompt Studio** 标签页，以同一组件列表展示运行时原生提示词和用户补充，并提供编辑、原生覆盖与完整请求预览。
