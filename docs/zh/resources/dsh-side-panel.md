# dsh-side-panel

> ⭐ 16 · 💤 停更 · 插件

## 一句话介绍

紧凑侧边栏：文件浏览器、终端与 Git 审查。

## 详细介绍

DSH Web 的右侧工作区面板，在当前会话旁集中提供 Git 审查、终端和文件操作。 可以点击dsh会话区弹出的文件链接，会自动打开相应的文件以供审阅。
