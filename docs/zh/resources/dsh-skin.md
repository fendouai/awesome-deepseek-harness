# dsh-skin

> ⭐ 11 · ✅ 活跃 · 插件

## 一句话介绍

Codex 风格皮肤切换器 + 自定义半透明壁纸，支持透明度/模糊控制。

## 详细介绍

Skin switcher + custom wallpaper for DeepSeek Harness — a "change the skin" feature in the spirit of Codex themes. It registers a curated catalog of palettes into DSH's built-in theme runtime and adds two rows to **Settings → General** (below the built-in Appearance row): - **皮肤 / Skins** — pick one of 7 curated palettes (or **默认 / Default** to follow the built-in appearance). - **背景图片 / Wallpaper** — set your own background image with opacity and blur controls.
