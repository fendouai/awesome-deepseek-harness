# dsh-plugin-spur

> ⭐ 3 · ✅ 活跃 · 工作流

## 一句话介绍

聊天流中悬挂皮鞭：甩动鞭梢即向 agent 发送 go work 消息（整活）。

## 详细介绍

一根悬挂在 DSH 聊天流中的辫子（皮鞭）。抓住辫梢甩动——速度足够快时，向 agent 发送一条 `go work!` 消息，鞭策它去干活。
