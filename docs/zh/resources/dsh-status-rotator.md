# dsh-status-rotator

> ⭐ 8 · ✅ 活跃 · 插件

## 一句话介绍

将 'Deep diving…' 状态替换为阶段感知的打字机消息。

## 详细介绍

把 DeepSeek Harness(dsh)Web 界面底部回合运行时那行 `Deep diving...` 状态文字,替换成自定义文案:按回合阶段切换、打字机逐字输出、流动炫彩渐变(可关)、定时轮换。运行时长时钟(15 秒后出现)不受影响。
