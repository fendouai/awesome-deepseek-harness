# dsh-suggested-replies

> ⭐ 3 · ✅ 活跃 · 插件

## 一句话介绍

DSH Web 预测回复插件：AI 回复后在输入框上方生成可点击填入草稿的候选。

## 详细介绍

DSH Web 的“预测回复”插件：AI 回复结束后，生成几条用户下一步可能会发送的消息候选，并将它们显示在**聊天输入框上方**。点击候选只会将文本填入输入框，**不会自动发送**。
