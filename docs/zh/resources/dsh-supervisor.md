# dsh-supervisor

> ⭐ 1 · ✅ 活跃 · 智能体

## 一句话介绍

同运行时跨会话发现与通信。

## 详细介绍

Let live [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Sessions discover, message, and coordinate with each other inside the same running DSH process. - Runs inside the existing `dsh` runtime - Starts no daemon, second agent runtime, or separate network port - Installs as a normal DSH plugin **Current release:** `@wha1echai/dsh-cross-session@0.1.0-rc.1` for DSH `0.1.0-rc.6`.
