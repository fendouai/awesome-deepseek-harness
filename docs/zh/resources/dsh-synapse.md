> A visual, non-linear conversation workspace plugin for DeepSeek Harness ; A canvas-based session explorer and branching workspace for DeepSeek Harness.

## 详细介绍

需要支持 profile 插件机制的 DeepSeek Harness、Node.js `>= 22.19.0`，以及 `web` profile。 corepack pnpm dsh plugin --profile web add dsh-synapse corepack pnpm dsh web 启动后，在 DSH 顶部切换到 **会话地图**。Synapse 复用现有的 DSH Web Server，不会启动第二个应用或代理系统。

## 📦 安装

```bash
corepack pnpm dsh plugin --profile web add dsh-synapse
corepack pnpm dsh web
```

## 🚀 快速开始

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm run build
corepack pnpm test
```
