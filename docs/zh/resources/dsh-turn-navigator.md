## 一句话介绍

> Private DSH Web turn navigation plugin

## 详细介绍

A compact turn navigator for long DSH Web conversations. It follows the conversation scroll, previews a user turn on hover, and jumps to that turn on click. It stays hidden until the conversation contains at least three user turns.

## 📦 安装

```bash
dsh plugin --profile web add -w "/path/to/dsh-turn-navigator"
dsh web
```

## 🚀 快速开始

```bash
dsh plugin --profile web add -w github:dsh-external/dsh-turn-navigator#<reviewed-commit>
```

## 📚 更多信息

**Installation**

The plugin is private and not published. Its private repository is `dsh-external/dsh-turn-navigator`, but the repository remains empty until the first reviewed push. Use the local installation path until a reviewed commit is available, then start Web: dsh plugin --profile web add -w "/path/to/dsh-turn-navigator" dsh web After the first reviewed commit is pushed, install that exact private revision
