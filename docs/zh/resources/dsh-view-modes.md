## 一句话介绍

Verbose/Normal/Summary 三种输出模式，工具调用与思考语义分组。

## 详细介绍

<div align="center"> **English** · [简体中文](./README.zh-CN.md) </div> <p align="center">Three output modes for DeepSeek Harness (DSH) Web: Verbose, Normal, and Summary. Keep the full trace when debugging, reduce process noise during daily work, or focus on the result.</p> This is an official-style DSH bundle plugin (`dsh.bundle` + `dsh.client`). It changes only browser-side presentation and does not patch DSH core files.
