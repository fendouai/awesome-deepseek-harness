# dsh-voice-webspeech

> ⭐ 0 · ✅ 活跃 · 插件

## 一句话介绍

Browser Web Speech API voice input for DSH: zero server, zero keys, zero model downloads (Edge=Azure, Chrome=Google speech).

## 详细介绍

DSH Web GUI 的**纯浏览器语音输入**插件：零服务端、零 API Key、零模型下载、零 Python。 按住输入框旁的麦克风按钮说话，松手即把语音转成文字——转写完全由**浏览器内置语音识别** （Web Speech API）完成：
