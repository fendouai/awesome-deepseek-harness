## 详细介绍

中文网文剧情检索 Skill —— 查询网络小说的剧情梗概、后续发展、具体章节内容、角色/设定细节。**通过免费转载站实现，不依赖起点等付费平台。** 适用于 DeepSeek Harness（DSH）等支持 Skill 概念的 Agent 框架。

## ✨ 核心特性

- 用户问「这本小说的剧情/后续/某章内容」→ 快速定位并总结
- 用户报出剧情线索（招式名/场景/角色名）→ 定位到对应章节
- 判断小说是否完结/断更，核实最新章号
