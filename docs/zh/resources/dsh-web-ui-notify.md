## 详细介绍

**Install:** `dsh plugin --profile web add github:bill9109/dsh-web-ui-notify` **A DeepSeek Harness Web UI client plugin: when a tool needs approval, DSH asks you a question, or a turn finishes while you are looking at another tab, it pops a system desktop notification — so neither DSH nor you end up waiting.** [English](README.md) | [中文](README.zh.md)
