## 详细介绍

WPS / 金山文档 (WPS Cloud Docs) integration for DeepSeek Harness (DSH). Talk to your **WPS cloud drive** in the DSH conversation: list / search / read / create / upload-download cloud documents, and read / write their text / spreadsheet / presentation / PDF content.
