## 详细介绍

**DeepSeek Harness · 一人一书 · 万界文字冒险** 这不是聊天机器人。这是**十九个世界的入口**。 在 DeepSeek Harness 里开一个会话，选一张界图，点一下「启程」——第一段正文砸下来。没有欢迎语，没有「作为 AI 我建议你」，没有第四面墙。bash、改文件、子代理，全部收刀。文学 preset **诸天万界DSH** 只许模型吐小说正文。 你要的不是助手。你要的是世界自己在呼吸。 **当前 0.4.13** · 仓库 InfiniteDSH · 组合包 `dsh-infinite` ---

## 📦 安装

```bash
dsh plugin --profile web add github:vdnight89/InfiniteDSH
dsh web
```

## 🚀 快速开始

```bash
/new 修仙
/new 末世 周慎
/new 都市 林晏 force
/new 深海实验室 阿澜
```
