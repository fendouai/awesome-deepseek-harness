## 详细介绍

**Author / Maintainer:** [@Zacklinkk](https://github.com/Zacklinkk) ADHD 的全名是 **Awesome DeepSeek Harness Desktop**。 它把 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 装进一个 Electron 桌面应用里。下载安装包、双击打开，就能使用 Harness，不需要自己安装 Node.js，不需要敲 `dsh web`，也不需要一直开着浏览器。

## ✨ 核心特性

- Windows 10 / 11（64 位）
- macOS 12 Monterey 及以上（Apple 芯片或 Intel 64 位）
- Linux x64（实验性支持）

## 📦 安装

```bash
npm install
npm start
```

## 🚀 快速开始

```bash
npm run check
```

## 📚 更多信息

**普通用户怎么安装？**

安装包会由 GitHub Actions 自动生成，并且只有在安装包真正启动、Harness 后台服务就绪、界面完成渲染后，构建才会显示成功。打开仓库的 **Actions** 页面，进入最近一次成功的 `Build desktop installers`，在页面底部下载自己系统对应的文件： 目前安装包还没有购买商业代码签名证书：
