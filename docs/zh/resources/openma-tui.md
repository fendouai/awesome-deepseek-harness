# DeepSeek Harness TUI (openma-ai)

> ⭐ 25 · ✅ 活跃 · 客户端

## 一句话介绍

Rust/Ratatui 终端客户端，直接与 DSH 的 SDK JSON-RPC 协议通信。

## 详细介绍

需要已安装并配置好的 `dsh`（当前集成基线为 `0.1.0-rc.6`）、Node.js 18+ 和 pnpm 10+。官方包覆盖 macOS Apple Silicon、macOS Intel、Linux x64 和 Windows x64。 dsh plugin --profile tui add @openma/deepseek-harness-tui dsh --profile tui 安装命令不需要 `-w`。可用下面的命令确认 bundle 已挂载为 `tui-runner`： dsh --profile tui --dump-config
